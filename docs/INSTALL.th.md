# คู่มือติดตั้ง EdgeDesk บน GitHub + Cloudflare (เก็บข้อมูลบนคลาวด์)

คู่มือนี้พาติดตั้ง EdgeDesk เวอร์ชันคลาวด์ตั้งแต่ศูนย์ ทำผ่านหน้าเว็บทั้งหมด **ไม่ต้องใช้ Terminal** ใช้เวลาประมาณ 20–30 นาที

> หน้าจอของ GitHub และ Cloudflare เปลี่ยนชื่อเมนูบ่อย ถ้าชื่อปุ่มในคู่มือไม่ตรงกับที่เห็น ให้มองหาคำที่ใกล้เคียง เช่น "Create", "Import", "Settings"

---

## ภาพรวม

```
 เบราว์เซอร์ (มือถือ / คอม)                    Cloudflare (บัญชีของคุณ)
 ┌──────────────────────┐   HTTPS + รหัสผ่าน   ┌──────────────────────────────┐
 │ EdgeDesk             │ ───────────────────▶ │ Worker "edgedesk"            │
 │ • สำเนาในเครื่อง      │                      │  • หน้าแอป  (public/)          │
 │   (ใช้ตอนออฟไลน์)     │ ◀─────────────────── │  • /api/*   (worker/index.js)  │
 └──────────────────────┘     ข้อมูล / รูป      │        │                      │
                                               │        ▼                      │
 GitHub (โค้ด) ── push ──▶ Cloudflare Builds ──▶ │ D1 database "edgedesk"        │
                          (deploy อัตโนมัติ)     │  เทรด · โน้ต · ตั้งค่า · รูป    │
                                               └──────────────────────────────┘
```

- **GitHub** เก็บโค้ด ทุกครั้งที่อัปโหลดไฟล์ใหม่ Cloudflare จะ deploy ให้เอง
- **Cloudflare Worker** ทำหน้าที่ส่งหน้าแอป และเป็น API สำหรับอ่าน/เขียนข้อมูล
- **Cloudflare D1** คือฐานข้อมูลที่เก็บข้อมูลทั้งหมด รวมถึงภาพหน้าจอ
- **การเข้าใช้** ต้องใส่รหัสผ่านที่คุณตั้งเอง (จำไว้ในเบราว์เซอร์ 30 วัน)
- **ใช้ได้หลายอุปกรณ์** แก้จากเครื่องหนึ่ง เครื่องอื่นเห็นภายในประมาณ 30 วินาที หรือทันทีที่กลับมาที่แท็บ
- **ใช้ตอนออฟไลน์ได้** แอปเก็บสำเนาในเบราว์เซอร์ด้วย แก้ไขต่อได้ แล้วจะซิงก์ให้เมื่อกลับมาออนไลน์

## สิ่งที่ต้องมี

| สิ่งที่ต้องมี | หมายเหตุ |
|---|---|
| บัญชี GitHub | สมัครฟรีที่ github.com |
| บัญชี Cloudflare | สมัครฟรีที่ dash.cloudflare.com · แพ็กเกจ Free เพียงพอสำหรับใช้คนเดียว |
| ไฟล์ชุดนี้ (`edgedesk-cloud-…zip`) | แตกไฟล์ไว้ในคอมพิวเตอร์ก่อน |
| ไฟล์สำรองจาก EdgeDesk เดิม (ถ้ามี) | ในแอปเดิม: ตั้งค่า → ข้อมูล → **ส่งออกไฟล์สำรอง (JSON)** |

---

## ขั้นที่ 1 — สร้าง repository บน GitHub แล้วอัปโหลดไฟล์

1. เข้า github.com → มุมขวาบนกด **+** → **New repository**
2. ตั้งชื่อ เช่น `edgedesk`
3. เลือก **Private** (แนะนำ เพื่อให้คนอื่นไม่เห็นโค้ด) → กด **Create repository**
4. ในหน้า repo ใหม่ กดลิงก์ **uploading an existing file**
5. ลาก **ทุกไฟล์และทุกโฟลเดอร์ที่อยู่ข้างใน** โฟลเดอร์ที่แตกจาก zip ไปวาง ได้แก่:
   - `src/` · `worker/` · `public/` · `docs/`
   - `build.mjs` · `package.json` · `wrangler.jsonc` · `README.md` · `.gitignore`
   - ลากไฟล์ที่อยู่ข้างในไปวางตรง ๆ ไม่ใช่ลากโฟลเดอร์ที่ครอบอยู่ด้านนอก
6. เลื่อนลงล่าง กด **Commit changes**

> ไฟล์ `.gitignore` ขึ้นต้นด้วยจุด ใน macOS / Windows อาจถูกซ่อนไว้ ถ้าไม่เห็นก็ข้ามได้ ไม่มีผลต่อการใช้งาน

---

## ขั้นที่ 2 — สร้างฐานข้อมูล D1

1. เข้า dash.cloudflare.com → เมนูซ้าย **Storage & databases** → **D1 SQL database**
2. กด **Create Database**
3. ตั้งชื่อ `edgedesk`
4. **Location** (ถ้ามีให้เลือก) เลือก **Asia-Pacific** เพื่อให้เร็วสำหรับผู้ใช้ในไทย
5. กด **Create**
6. ในหน้าฐานข้อมูลที่สร้างเสร็จ จะมี **Database ID** เป็นรหัสยาว ๆ เช่น `3f2a9c1e-…` → **กดคัดลอกเก็บไว้**

> ไม่ต้องสร้างตารางเอง Worker จะสร้างตารางให้อัตโนมัติตอนใช้งานครั้งแรก

---

## ขั้นที่ 3 — ใส่ Database ID ในไฟล์ `wrangler.jsonc`

1. กลับไปที่ repo บน GitHub → เปิดไฟล์ `wrangler.jsonc`
2. กดไอคอน **ดินสอ (Edit this file)** มุมขวาบน
3. หาบรรทัดนี้

   ```jsonc
   "database_id": "PASTE-YOUR-D1-DATABASE-ID-HERE"
   ```

   แล้วแทนที่ข้อความระหว่างเครื่องหมายคำพูดด้วย Database ID ที่คัดลอกมา เช่น

   ```jsonc
   "database_id": "3f2a9c1e-1234-4abc-9def-0123456789ab"
   ```

4. กด **Commit changes…** → **Commit changes**

> ห้ามเปลี่ยน `"name": "edgedesk"` ในไฟล์นี้ ชื่อนี้ต้องตรงกับชื่อ Worker ในขั้นถัดไป

---

## ขั้นที่ 4 — สร้าง Worker และเชื่อมกับ GitHub

1. ใน Cloudflare → เมนูซ้าย **Workers & Pages** → กด **Create application**
2. เลือก **Import a repository** (หรือแท็บ / ปุ่ม **GitHub**)
3. ถ้าเป็นครั้งแรก กด **Connect GitHub** แล้วอนุญาตให้ Cloudflare เข้าถึง repo `edgedesk` (เลือกเฉพาะ repo นี้ก็ได้)
4. เลือก repo `edgedesk`
5. ตั้งค่าตามนี้

   | ช่อง | ค่าที่ใส่ |
   |---|---|
   | Project / Worker name | `edgedesk` (ต้องตรงกับ `name` ใน `wrangler.jsonc`) |
   | Build command | `npm run build` |
   | Deploy command | `npx wrangler deploy` (ค่าเริ่มต้น) |
   | Root directory | เว้นว่าง หรือ `/` |
   | Production branch | `main` |

6. กด **Save and Deploy** (หรือ **Deploy**) แล้วรอ 1–3 นาที จนสถานะเป็น **Success**
7. Cloudflare จะให้ลิงก์หน้าตาแบบ `https://edgedesk.<ชื่อบัญชี>.workers.dev` นี่คือที่อยู่ของแอป

> ถ้าเปิดลิงก์ตอนนี้ จะเห็นหน้า Login ที่แจ้งว่า "ยังไม่ได้ตั้งรหัสผ่าน" ซึ่งถูกต้องแล้ว ให้ทำขั้นที่ 5 ต่อ

---

## ขั้นที่ 5 — ตั้งรหัสผ่านเข้าแอป

1. **Workers & Pages** → เลือก Worker `edgedesk` → แท็บ **Settings**
2. หัวข้อ **Variables and Secrets** → กด **Add**
3. ตั้งค่าดังนี้
   - **Type:** `Secret`
   - **Variable name:** `APP_PASSWORD`
   - **Value:** รหัสผ่านที่ต้องการ (แนะนำอย่างน้อย 12 ตัวอักษร ผสมตัวเลขและสัญลักษณ์)
4. กด **Deploy** (หรือ **Save and deploy**)

**ไม่บังคับ:** เพิ่ม Secret ชื่อ `SESSION_SECRET` เป็นข้อความสุ่มยาว ๆ
- ใช้เป็นกุญแจลงลายเซ็นของการ Login
- ถ้าวันหนึ่งอยากให้ทุกอุปกรณ์ออกจากระบบพร้อมกัน ให้เปลี่ยนค่านี้

> Secret ไม่ถูกเขียนทับเวลา deploy เวอร์ชันใหม่ ตั้งครั้งเดียวพอ

---

## ขั้นที่ 6 — เข้าใช้งานและย้ายข้อมูลเดิม

1. เปิดลิงก์ `https://edgedesk.<ชื่อบัญชี>.workers.dev` → ใส่รหัสผ่าน → **เข้าสู่ระบบ**
2. ถ้ามีข้อมูลจาก EdgeDesk เดิม: **ตั้งค่า → ข้อมูล & สำรอง → กู้คืนจากไฟล์สำรอง** → เลือกไฟล์ JSON → **ยืนยัน**
3. รอให้มุมซ้ายล่างขึ้น **"ซิงก์ขึ้นคลาวด์แล้ว"** เป็นอันเสร็จ
   - ถ้ามีภาพหน้าจอเยอะ อาจใช้เวลาหลายนาที
   - ดูจำนวนรูปที่ยังรออัปโหลดได้ใน ตั้งค่า → ข้อมูล → ซิงก์คลาวด์
4. เปิดลิงก์เดียวกันบนมือถือหรือคอมพิวเตอร์เครื่องอื่น แล้ว Login → จะเห็นข้อมูลชุดเดียวกัน

> **มือถือ:** เปิดลิงก์ใน Safari / Chrome → เมนูแชร์ → **Add to Home Screen** จะได้ไอคอนเปิดแอปเหมือนแอปทั่วไป

---

## (ไม่บังคับ) ใช้โดเมนของตัวเอง

ถ้ามีโดเมนอยู่ใน Cloudflare แล้ว:
1. Worker `edgedesk` → **Settings** → **Domains & Routes** → **Add** → **Custom domain**
2. ใส่ เช่น `journal.example.com` → **Add domain**

Login แยกตามโดเมน ถ้าเปลี่ยนไปใช้โดเมนใหม่ ต้อง Login ใหม่หนึ่งครั้ง

## (ไม่บังคับ) เพิ่มชั้นป้องกันด้วย Cloudflare Access

ถ้าต้องการให้ Cloudflare ตรวจตัวตนอีกชั้นก่อนถึงหน้า Login ของแอป เช่น ต้องยืนยันด้วยอีเมลของคุณ:
1. Worker `edgedesk` → แท็บ **Access** → **Protect this Worker behind Access**
2. เลือก **All traffic** → เลือก policy (เช่น อนุญาตเฉพาะบัญชี Cloudflare ของคุณ) → **Apply Access**

ต้องเปิดใช้ Cloudflare Zero Trust ในบัญชีก่อน ถ้ายังไม่เคยใช้ ระบบจะพาไปตั้งค่า

## การอัปเดตเป็นเวอร์ชันใหม่

เมื่อได้ไฟล์ชุดใหม่ (zip):
1. เปิด repo บน GitHub → **Add file → Upload files**
2. ลากโฟลเดอร์ `src/`, `public/`, `worker/` และไฟล์ `build.mjs`, `package.json` จากชุดใหม่ไปวาง ไฟล์ชื่อซ้ำจะถูกแทนที่
   - **ห้ามอัปโหลด `wrangler.jsonc` ทับ** เพราะจะลบ Database ID ที่ใส่ไว้
   - ถ้าต้องอัปโหลดไฟล์นี้ ให้ใส่ ID ใหม่อีกครั้งตามขั้นที่ 3
3. กด **Commit changes** → Cloudflare จะ deploy ให้อัตโนมัติภายในไม่กี่นาที
   - ดูสถานะได้ที่ Worker → แท็บ **Deployments** หรือ **Builds**
4. เปิดแอปแล้วกดรีเฟรช 1 ครั้ง แล้วเช็กเลขเวอร์ชันที่มุมซ้ายบน

**ข้อมูลไม่หาย** เพราะการอัปเดตเปลี่ยนแค่ตัวโปรแกรม ข้อมูลอยู่ใน D1 แยกต่างหาก

---

## การสำรองข้อมูล

- **ไฟล์สำรอง JSON** ใช้ได้เหมือนเดิม: ตั้งค่า → ข้อมูล → **ส่งออกไฟล์สำรอง** ไฟล์รวมภาพหน้าจอทุกภาพ รวมถึงภาพที่อัปโหลดจากเครื่องอื่น
- **สำรองอัตโนมัติลงโฟลเดอร์** ยังใช้ได้บน Chrome / Edge ในคอมพิวเตอร์
- **ฐานข้อมูล D1** มีระบบย้อนเวลาของ Cloudflare (Time Travel) เป็นอีกชั้น ดูได้ที่หน้า D1 → `edgedesk`

แนะนำให้ส่งออกไฟล์สำรองเก็บไว้เป็นครั้งคราว แม้ข้อมูลจะอยู่บนคลาวด์แล้วก็ตาม

---

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| Deploy ไม่ผ่าน ขึ้นว่าชื่อ Worker ไม่ตรง | ชื่อ Worker ใน Cloudflare ต้องเป็น `edgedesk` ตรงกับ `name` ใน `wrangler.jsonc` |
| Deploy ไม่ผ่าน ขึ้นเรื่อง `database_id` | ยังไม่ได้ใส่ Database ID หรือใส่ผิด ทำขั้นที่ 3 ใหม่ (คัดลอก ID จากหน้า D1 อีกครั้ง) |
| หน้า Login ขึ้น "ยังไม่ได้ตั้งรหัสผ่าน" | ยังไม่ได้เพิ่ม Secret `APP_PASSWORD` หรือยังไม่ได้กด Deploy หลังเพิ่ม (ขั้นที่ 5) |
| ใส่รหัสถูกแต่เข้าไม่ได้ / ขึ้น "ลองผิดหลายครั้งเกินไป" | ใส่ผิดเกิน 8 ครั้ง ระบบล็อก 15 นาที รอแล้วลองใหม่ |
| ขึ้น `D1 binding "DB" is missing` | `wrangler.jsonc` ไม่มีส่วน `d1_databases` หรือถูกอัปโหลดทับ ใส่กลับตามไฟล์ต้นฉบับ |
| มุมซ้ายล่างขึ้น "ยังไม่ได้ซิงก์ — จะลองใหม่" | เน็ตหลุดชั่วคราว ข้อมูลยังอยู่ในเครื่อง ระบบลองใหม่ทุก 15 วินาที หรือกด "ซิงก์ตอนนี้" ในหน้าตั้งค่า |
| เครื่องอื่นยังไม่เห็นข้อมูลล่าสุด | รอประมาณ 30 วินาที หรือสลับแท็บออกแล้วกลับมา ถ้าเปิดหน้าแก้ไขค้างไว้ ระบบจะรอจนปิดหน้าแก้ไขก่อน |
| แก้รายการเดียวกันพร้อมกันสองเครื่อง | ระบบเก็บการบันทึกครั้งล่าสุด (last write wins) |
| ลืมรหัสผ่าน | เปลี่ยนค่า Secret `APP_PASSWORD` ใน Cloudflare แล้ว Deploy ข้อมูลไม่หาย |

ดู log ของ Worker ได้ที่ Worker → แท็บ **Logs** / **Observability**

## สำหรับนักพัฒนา (ไม่จำเป็นสำหรับผู้ใช้ทั่วไป)

```bash
npm install
echo "APP_PASSWORD=dev-password" > .dev.vars
npm run build        # สร้าง public/index.html (คลาวด์) และ dist/ (ไฟล์เดียวแบบ standalone)
npm run dev          # http://localhost:8787 ใช้ D1 จำลองในเครื่อง
npx wrangler deploy  # deploy เองโดยไม่ผ่าน GitHub (ต้อง wrangler login ก่อน)
```

| ไฟล์ / โฟลเดอร์ | หน้าที่ |
|---|---|
| `src/` | โค้ดแอปทั้งหมด (ชุดเดียวกับ standalone) |
| `src/cloud.js` | ส่วนซิงก์กับคลาวด์ ทำงานเฉพาะใน build คลาวด์ |
| `build.mjs` | `node build.mjs --cloud` → `public/index.html`<br>`node build.mjs` → `dist/EdgeDesk_v….html` |
| `worker/index.js` | API: login, `/api/state`, `/api/sync`, `/api/images` และสร้างตาราง D1 อัตโนมัติ |
| `wrangler.jsonc` | ตั้งค่า Worker, static assets และ D1 binding |
